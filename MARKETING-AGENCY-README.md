# 🚀 NEXUS - Landing Page Agencia de Marketing Digital

## 🎨 Diseño Disruptivo

Landing page ultra moderna para agencia de marketing digital con diseño no convencional usando **Tailwind CSS**.

## ✨ Características

### Diseño Visual
- **Glassmorphism**: Efectos de vidrio esmerilado con blur
- **Gradientes Neón**: Colores vibrantes (rosa, azul, morado, verde)
- **Animaciones Flotantes**: Elementos que flotan y rotan
- **Blobs Animados**: Formas orgánicas en el fondo
- **Cursor Personalizado**: Experiencia interactiva única
- **Efectos de Glow**: Sombras neón en botones y elementos clave

### Secciones

1. **Hero Section**
   - Título impactante con texto en degradado y stroke
   - Estadísticas de ROI y métricas
   - Elementos visuales 3D animados (círculos y cuadrados rotativos)
   - CTAs prominentes

2. **Servicios (Grid Asimétrico)**
   - **Branding Disruptivo**: Identidad visual completa
   - **Social Media**: Gestión de redes (Instagram, TikTok, Facebook, Twitter)
   - **Meta Ads**: Campañas en Facebook e Instagram
   - **Google Ads & AdSense**: Posicionamiento SEM y monetización
   - **Influencer Marketing**: Campañas con creadores de contenido
   - **Analytics & Growth**: Optimización basada en datos

3. **Proceso**
   - Metodología en 4 pasos
   - Visualización clara del flujo de trabajo

4. **CTA Final**
   - Llamado a la acción con estadísticas
   - Opciones de contacto múltiples

5. **Footer**
   - Links a servicios
   - Redes sociales
   - Información de contacto

## 🎨 Personalización

### Cambiar colores
Edita la configuración de Tailwind en el `<script>`:

```javascript
tailwind.config = {
  theme: {
    extend: {
      colors: {
        'neon-pink': '#TU_COLOR',
        'neon-blue': '#TU_COLOR',
        // ...
      }
    }
  }
}
```

### Modificar animaciones
Las animaciones están definidas en los keyframes de Tailwind config:
- `float`: Flotación suave
- `pulse-glow`: Pulso luminoso
- `slide-in`: Entrada lateral
- `rotate-slow`: Rotación lenta
